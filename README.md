Jalist is an REPL app programmed in java. it allows to handle and modify strings of characters.
Java project type : Maven


# REPL : REPL stands for Read-Eval-Print Loop

The Core Cycle
The name comes from the three primary functions that implement the loop:

Read: Accepts an expression from the user and parses it into a data structure in memory. 
Eval: Evaluates the internal data structure to determine its meaning and result.
Print: Outputs the result yielded by eval to the user, often in a textual format that can be copied and pasted back into the REPL

Loop : do it in loop.
